🛒 Online Shop

A full-stack E-Commerce web application built with Angular, Spring Boot, and PostgreSQL. The application provides a modern shopping experience where users can browse products, manage their cart, and place orders through a responsive interface backed by a secure REST API.

⚙️ Installation
1. Clone the repository
git clone https://github.com/Mohamedtamer22/Online-Shop.git
2. Backend
cd Back-end/online-shop_src

Update your PostgreSQL credentials inside the Spring Boot configuration file.

Run the application:

mvn spring-boot:run
3. Database

Create a PostgreSQL database.

Import:

electro_hub.sql
4. Frontend
cd "Front end (Angular)/electrohub_v1.1.0"
npm install
ng serve

Open:

http://localhost:4200
